# 版本控制与 Git
## 概述
### VCS 定义：跟踪文件变化、维护历史、促进协作
### 为什么有用：查看旧快照 / 记录变更原因 / 并行分支 / 解决冲突
### 现代 VCS 能自动回答
#### 谁写了这个模块？
#### 某行何时 / 由谁 / 为何被编辑？
#### 某个测试何时 / 为何停止工作？
### Git 已成事实标准（XKCD 1597）
### 学习路径：先数据模型（自下而上）再命令行
## Git 的数据模型
### 快照
#### blob：文件（一堆字节）
#### tree：目录，名称 → blob / tree 映射
#### 快照 = 被跟踪的顶层树
#### 示例：root(tree) → foo(tree) → bar.txt(blob)
### 建模历史：关联快照
#### 不用线性历史 → 历史是有向无环图（DAG）
#### 提交 = 快照，引用一组父提交
#### 合并 = 一个快照来自多个父提交
#### 提交不可变：修改历史 = 新建提交 + 更新引用
### 数据模型（伪代码）
#### blob = array<byte>
#### tree = map<string, tree | blob>
#### commit = { parents, author, message, snapshot }
### 对象与内容寻址
#### object = blob | tree | commit
#### 所有对象通过 SHA-1 哈希内容寻址
#### 对象间通过哈希引用（不内嵌内容）
#### git cat-file -p 查看对象内容
### 引用（references）
#### SHA-1 对人类不友好 → 引用 = 指向提交的可变指针
#### 对象不可变、引用可变
#### HEAD = 特殊引用，表示“当前所在位置”
### 仓库 = objects + references
#### 所有 git 命令 = 操作提交 DAG + 添加/更新引用
#### 思考每条命令对底层图数据结构做了什么
## 暂存区
### 与数据模型正交，是创建提交的接口
### 指定哪些修改进入下一个快照
### 场景：两个独立功能 → 两个提交；调试打印 vs bug 修复分开提交
## Git 命令行界面
### 基础
#### git help <command> 获取帮助
#### git init 创建仓库（数据存 .git）
#### git status 查看当前状态
#### git add <filename> 加入暂存区
#### git commit 创建提交（写好提交信息！）
#### git log / --all --graph --decorate 可视化 DAG
#### git diff <filename> / <revision> 查看差异
#### git checkout <revision> 更新 HEAD
### 分支与合并
#### git branch / branch <name> 显示 / 创建分支
#### git switch <name> 切换分支
#### git checkout -b <name> 创建并切换分支
#### git merge <revision> 合并到当前分支
#### git mergetool 图形化解决合并冲突
#### git rebase 把补丁重新应用到新基础
### 远程仓库
#### git remote / remote add <name> <url>
#### git push <remote> <local>:<remote>
#### git branch --set-upstream-to 设置对应关系
#### git fetch 检索对象/引用
#### git pull = fetch + merge
#### git clone 从远程下载仓库
### 撤销
#### git commit --amend 编辑提交内容/信息
#### git reset <file> 取消暂存
#### git restore 放弃更改
## 高级 Git
### git config：Git 高度可定制
### git clone --depth=1：浅克隆（无完整历史）
### git add -p：交互式暂存
### git rebase -i：交互式变基
### git blame：显示最后编辑每行的人
### git stash：暂时移除工作区修改
### git bisect：二分搜索历史（如回归测试）
### git revert：新提交撤销旧提交效果
### git worktree：同时检出多个分支
### .gitignore：指定要忽略的未跟踪文件
