## 文本编辑与Vim
### Vim哲学：界面是一种编程语言
#### 按键=命令，可组合
#### 避免鼠标和方向键
#### 速度能跟上思维
### Vim无处不在
#### VS Code → VSCodeVim插件
#### Zsh → 内建Vim支持
#### Claude Code → 内建Vim编辑模式
### 模态编辑（5种模式）
#### 正常模式 — 移动+编辑（默认模式）
#### 插入模式 — 输入文本（按i进入，ESC退出）
#### 替换模式 — 替换文本（按R进入）
#### 可视化模式 — 选择文本块
##### 普通：v
##### 行：V
##### 块：Ctrl-v
#### 命令模式 — 运行命令（按:进入）
### 核心技巧：频繁按ESC → 建议Caps Lock映射为Escape
### Vim编程语言 = 名词 + 动词 + 修饰符 + 计数
#### 名词：移动命令
##### 基础：h← j↓ k↑ l→
##### 单词：w(下个词) b(词头) e(词尾)
##### 行：0(行首) ^(首非空) $(行尾)
##### 屏幕：H(顶) M(中) L(底)
##### 滚动：Ctrl-u(上翻) Ctrl-d(下翻)
##### 文件：gg(文件头) G(文件尾)
##### 行号：{n}G 或 :{n}
##### 匹配：% (括号/花括号)
##### 当前行查找：f{char} t{char} F{char} T{char}
##### 全局搜索：/{regex} → n/N导航
#### 动词：编辑命令
##### i → 进入插入模式
##### o/O → 下方/上方开新行
##### d{motion} → 删除（如dw删词 d$删到行尾）
##### c{motion} → 修改（= 删除+插入）
##### x → 删字符 / s → 替换字符
##### 可视化模式+d/c → 选中后删除/修改
##### u → 撤销 / Ctrl-r → 重做
##### y → 复制(拖拽) / p → 粘贴
##### ~ → 切换大小写 / J → 连接多行
#### 计数：重复执行
##### 3w → 前进3词
##### 5j → 下移5行
##### 7dw → 删除7词
#### 修饰符：改变名词含义
##### i = inner/inside（内部）
##### a = around（包含边界）
##### ci( → 修改括号内内容
##### ci[ → 修改方括号内内容
##### da' → 删除单引号字符串（含引号）
### 实战：修复Fizz Buzz
#### 1. 末尾添加main调用 → G + o + 输入代码
#### 2. 修改range从1开始 → /range搜索 → ww → i插入1,
#### 3. 修改fizz为buzz → :6跳行 → ci"修改引号内容
### 学习Vim的方法

## 代码智能与语言服务器
### 核心概念：Language Server Protocol (LSP)
#### VS Code Python扩展 → Pylance
#### VS Code Go扩展 → gopls
### 五大功能
#### 代码补全：更强的自动补全/字段方法提示
#### 内联文档：悬停查看文档
#### 跳转到定义：从引用跳到定义位置
#### 查找引用：反向查找所有引用
#### 代码质量：格式化/类型检查/linter
### 配置要点
#### 某些语言安装即用，某些需配置环境
#### Python需指向Python环境让LSP看到已安装包
#### 可对无类型注解的项目禁用静态类型检查
