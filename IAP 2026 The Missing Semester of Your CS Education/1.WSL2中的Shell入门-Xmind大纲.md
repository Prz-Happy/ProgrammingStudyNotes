# WSL2 中的 Shell 入门 — Xmind 大纲

> 基于 MIT 2026 IAP《The Missing Semester of Your CS Education》Shell 章节

## 1. Shell 是什么
- 计算机内工具之间互相交互的"工具"
- 三大优势
    - 自动化几乎所有任务
    - 跨平台通用（几乎所有平台都有 shell）
    - 开源社区标配
- 打开方式
    - Windows: `Win+R` → `cmd` / `powershell`
    - Linux: `Ctrl+Alt+T`
    - macOS: `Cmd+Space` → Terminal

## 2. Shell 基础操作
- `date` — 打印当前日期时间
- `echo` — 打印参数
    - Shell 按空白字符拆分 → 第一个单词=程序，后续=参数
    - 含空格/特殊字符：用引号包裹或 `\` 转义
- `man` / `--help` / `tldr` — 查命令帮助
- 路径与目录
    - `cd` — 切换工作目录（Shell 内建命令）
    - `pwd` / `echo $PWD` — 打印当前路径
    - `~` = home 目录，`.` = 当前，`..` = 父目录
    - 绝对路径（以 `/` 开头）vs 相对路径
    - 推荐 `zoxide` 加速 cd
- WSL2 文件系统特点
    - ext4 虚拟磁盘 + 自动挂载 Windows 盘到 `/mnt`
    - 跨系统访问 `\\wsl$\<发行版>`
    - ext4 性能是 NTFS 的 3-5 倍

## 3. Shell 程序查找机制
- `$PATH` — Shell 搜索命令的目录列表（冒号分隔）
- `which` — 查看命令对应文件路径
- 可直接用绝对路径绕过 `$PATH`
- `ls /bin` — 列出所有可用程序
- 常用文本处理工具
    - `cat` — 打印文件全部内容
    - `sort` — 按字典序排序
    - `uniq` — 去重连续重复行
    - `head` / `tail` — 前/后几行
    - `grep` — 匹配查找（支持正则，`-r` 递归搜索）
    - `sed` — 流编辑器（`-i` 原地修改，`s/pattern/replace/g` 替换）
    - `find` — 按条件递归查找文件
    - `awk` — 解析格式化数据（CSV等），提取列/过滤/统计
- 推荐替代工具：`eza` 替代 ls，`fd` 替代 find

## 4. Shell 编程语言特性
- 管道 `|`：前一个程序 stdout → 后一个程序 stdin（核心组合机制）
- 重定向
    - `> file` — stdout 写入文件（覆盖）
    - `>> file` — 追加写入
    - `< file` — 从文件读取 stdin
    - `<> file` — 读写模式打开（不清空）
    - `<<< "str"` — Here-String 单行输入
    - `2>&1` — stderr 合并到 stdout
    - `&> file` — Bash 4.0+ 一键合并（stdout+stderr）
    - `exec > log` — 永久重定向当前 Shell 进程的所有输出
    - `exec 3>&1 1>>logfile 2>&3` — stdout 入日志，stderr 上屏幕
- 条件与循环
    - `if command; then ...; fi`
    - `while command; do ...; done`
    - `for var in list; do ...; done`
    - `$(seq 1 10)` — 命令替换生成列表（推荐 `$()`，支持嵌套）
    - `test` / `[ ]` — 条件判断命令（注意空格）
        - 文件测试: `-d`/`-f`/`-e`/`-s`/`-r`/`-w`/`-x`
        - 字符串: `-z`/`-n`/`=`
        - 数值: `-eq`/`-ne`/`-gt`/`-ge`/`-lt`/`-le`（不可用 `>`/`<`）
    - `[[ ]]` — 升级版（推荐）
        - 防空变量不需引号保护
        - 原生 `&&`/`||` 短路逻辑
        - 支持 Glob 匹配 `== *.txt` 和正则 `=~`
- 脚本安全最佳实践
    - `#!/bin/bash` — Shebang 指定解释器
    - `set -euo pipefail` — 严格模式
        - `-e`：命令失败即退出
        - `-u`：未定义变量报错
        - `-o pipefail`：管道任一失败即失败
    - 使用 `shellcheck` 静态检查
    - 超 100 行建议迁移到 Python

## 5. 特殊符号深解
- `$` 全景
    - 变量取值: `$var` / `${var}` / `${1:-}`（防空默认值）
    - 位置参数: `$0`(脚本名) / `$1-$9` / `$@`(全部参数,保持独立性) / `$*`(合并为单串)
    - 状态: `$?`(退出码) / `$!`(后台PID) / `$#`(参数个数) / `$$`(当前PID)
    - 命令替换: `$(command)`
    - 算术扩展: `$((expr))`
    - ANSI-C 转义: `$'...'`
    - 本地化: `$"..."`（不推荐，有注入风险）
- `-` vs `--` vs `--help`
    - `-` = stdin/stdout 的虚拟文件名
    - `--` = 关闭参数解析，之后全当文件名
    - `--help` = GNU 现代选项
    - `-help` = 老 UNIX 风格（可能被拆成 `-h -e -l -p`）
- 三种引号
    - `'单引号'` — 强引用，一切字面量
    - `"双引号"` — 弱引用，`$` `` ` `` `\` 仍解析
    - `$'...'` — ANSI-C 转义（`\n`→换行, `\t`→制表）
- `[` vs `[[ ]]`
    - `[` = 普通命令(test别名)，空格必须，不支持 `--` 防御
    - `[[ ]]` = Bash 关键字，天⽣免疫 Flag 注入，支持短路+Glob+Regex

## 6. 标准流与重定向
- 三条标准流
    - `0` stdin — 默认键盘
    - `1` stdout — 默认屏幕
    - `2` stderr — 默认屏幕（独立于stdout，报错不污染正常输出）
- 分别重定向：`> stdout.log 2> stderr.log`
- 合并重定向：`> output.log 2>&1`（顺序关键，从左到右）
- exec 两种用法
    - A: `exec top` → 替换当前进程（退出即关闭终端）
    - B: `exec > log` → 永久重定向后续所有输出

## 7. Linux 文件系统核心
- 权限 `rwxrwxrwx`
    - 第1字符: `-`文件 / `d`目录 / `l`软链接
    - 后9字符: 所有者(rwx) + 用户组(rwx) + 其他人(rwx)
- 硬链接 vs 软链接
    - 硬链接: 同 Inode 号，删不干，不跨分区，不适用于目录
    - 软链接: 独立 Inode，存源路径文本，源删即死，可跨分区可链目录
- 命令类型
    - 内建命令: Shell 源码内 C 函数，无子进程，可改环境（cd/exit/echo）
    - 外部命令: 独立二进制文件，fork+exec 子进程，不可改父环境（ls/grep/g++）
    - 用 `type` 审查命令身份
- 子进程隔离原则
    - 子不能影响父: 工作目录/环境变量/内存变量/文件描述符
    - 子可反馈父: 退出状态码 `$?`（唯一通道）
    - 这解释了为什么 `cd` 必须是内建命令

## 8. 分组: find 命令
- 语法: `find [路径] [条件] [操作]`
- 核心条件
    - `-name`/`-iname` — 文件名（大小写敏感/不敏感）
    - `-type f/d/l` — 类型过滤
    - `-size +1G/-10k` — 大小过滤
    - `-mtime +30/-1` — 时间过滤
- 逻辑组合: `-a`(与,默认) / `-o`(或) / `!`(非)
- 后续操作
    - `-print`/`-print0` — 默认打印 / Null分隔（防空格）
    - `-delete` — 直接删除
    - `-exec cmd {} \;` — 逐文件执行（性能差）
    - 用 `xargs` + `-print0`/`-0` 批量处理（性能更好）

## 9. 实战习题要点
- Glob 通配符: `*`(任意多) / `?`(仅一个) / `[...]`(字符集) / `{a,b,c}`(大括号展开，不依赖磁盘文件)
- `${1:-}` = 变量防空默认值语法
- `[ -f "./$file" ]` = 老派 `[` 防御 Flag 文件名，挂路径前缀 `./` 破除
- `dos2unix` — 转 Windows 换行到 Unix
- `set -x` — 调试模式，每条命令执行前打印
- `$#` 检查参数个数（比 `$1` 安全，兼容 `set -u`）
- `| sort | uniq -c` = 管道统计模式（必须 sort 在 uniq 前）
- `curl -s` — 静默模式，不污染管道
- `jq` — JSON 处理（`.[]`解构数组 / `select()`条件 / `.field`提取）
- `awk` — 条件+动作：`awk '$2>100 {print $3,$2,$1}'`
- `paste -sd, -` — 纵向列表合并为逗号分隔单行
