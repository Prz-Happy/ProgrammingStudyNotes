## 正则表达式
### 定义：表示字符串集合的语言
### 应用：ag 全库搜索 / go test -run 选测试 / 校验与解析
### 示例模式
#### abc：字面量匹配
#### missing|semester：或匹配
#### \d{4}-\d{2}-\d{2}：日期格式（不校验合法性）
#### .+@.+：简易邮箱（会误报）
### 基本语法构件
#### . 任意字符
#### [abc] 字符集合 / [^abc] 排除 / [a-f] 范围
#### a|b 或
#### \d 数字 / \w 单词字符 / \b 单词边界
#### (...) 分组
#### ? 0或1次 / * 任意次数 / + 1次以上 / {N} 精确N次
#### \. 转义字面量 / \\ 反斜杠
#### ^ 行首 / $ 行尾
### 捕获组与引用
#### group(1) 提取子匹配（月份提取示例）
#### 编辑器替换：VS Code 用 $1 / Vim 用 \1
### 局限性
#### 正则语言有限：{a^n b^n} 不可表达、HTML 非正则
#### 现代引擎支持前瞻/反向引用 → 能力超出正则语言
#### 复杂解析用更强解析器（PEG：pyparsing）
### 学习建议：先学基础，按需查资料；LLM 可辅助生成 regex
## 练习
### 1. 配置格式化器 + linter + pre-commit；用 AI agent 修 linter 错误（需能运行并观察结果）
### 2. 学测试库写单元测试；跑覆盖率；用 AI agent 提高覆盖率（需逐行报告）
### 3. 配置 CI 每次 push 运行格式/lint/测试；故意弄坏代码验证能抓到
### 4. 写 regex 用 grep 找 subprocess.Popen(..., shell=True)，对比 semgrep
### 5. 用 regex 查找替换把讲义中的 - 项目符号换成 *（不能全量替换 - 字符）
### 6. 从 JSON 捕获 name：贪婪量词陷阱 → 转义引号 → 最终用 JSON 解析器一行搞定
